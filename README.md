# 단어타임

혼자 쓰는 영어 단어장 웹앱입니다. `index.html` 파일 하나로 동작합니다.

- 단어장: 단어 추가/수정/삭제, 묶음(Lesson) 구분, 카메라로 찍기 / 앨범에서 고르기로 사진 추가
- 암기: 플래시카드 (범위·순서·방향·답 가리기 선택, 좌우로 밀어서 넘기기)
- 퀴즈: 객관식/주관식, 오답노트 우선 출제, 연속 2번 정답 시 오답노트 졸업
- 통계: 암기율, 연속 학습일수, 오늘 학습시간, 최근 7일 그래프
- 저장과 백업: `wordtime-backup-날짜.json` 파일로 내보내기/가져오기

## 웹앱으로 쓰기 (추천)

GitHub Pages로 열면 폰 홈 화면에 앱처럼 설치해서 쓸 수 있어요.

- 주소: https://dk26029-cpu.github.io/wordtime/
- 폰에서 설치: 크롬은 메뉴(⋮) → "홈 화면에 추가" / 사파리는 공유 버튼 → "홈 화면에 추가"
- 설치 뒤에는 인터넷이 없어도 열려요. 사진 인식과 PDF 읽기도 한 번 쓴 뒤로는 인터넷 없이 돼요.
- 단어장은 그 기기 브라우저에 저장돼요. 다른 기기로 옮길 때는 통계 탭의 백업을 쓰세요.
- "카메라로 찍기"는 앱 안에서 카메라를 켜요. 노란 안내 칸에 단어장을 맞추고 찍으면 그 칸 부분만 읽어요.
  처음 한 번 카메라 허용을 물어봐요. 카메라를 못 켜면 폰의 기본 카메라 앱으로 찍게 안내해요.
- **PDF 단어장 불러오기 (가장 정확)**: 글자가 들어 있는 PDF 단어장을 고르면 사진 인식 없이 글자를 그대로 꺼내요.
  표 모양(번호 | 단어 | 뜻 | 별점)이나 두 단 페이지도 칸 위치로 나눠요. 범위를 고르고 20/30/50/100개씩
  "Day 1, Day 2…" 묶음으로 나눠 저장할 수 있어요. 같은 단어가 두 번 나오면 뜻을 " / "로 합쳐요.
  스캔한 그림 PDF는 글자가 없어서 못 읽어요. pdf.js(Apache-2.0)는 vendor/pdfjs에 들어 있어서 한 번 쓴 뒤로는 인터넷 없이도 돼요.
- 단어장 목록은 묶음별로 볼 수 있고, 100개씩 더 보기, 묶음 통째로 삭제가 돼요.
- **글자 붙여넣기**: 폰 카메라의 글자 인식이나 Google 렌즈로 단어장을 비추고 글자를 복사해서 붙여 넣으면
  단어와 뜻을 짝지어 줘요. 한 줄에 "단어 뜻"이 오든, 단어 목록과 뜻 목록이 따로 오든 둘 다 처리해요.
  안드로이드에서 홈 화면 앱으로 설치했다면 렌즈에서 공유 → 단어타임으로 바로 보낼 수 있어요.
- 사진은 Tesseract(무료 글자 인식)가 읽어요. 인식 파일(vendor/tesseract, 약 13MB 중 폰마다 필요한 8.6MB)이 앱 안에 들어 있어서
  처음 한 번 받은 뒤로는 비행기 모드에서도 인식돼요. 실제 교재에서는 한글 뜻 인식이 약해서 PDF나 글자 붙여넣기를 추천해요.
  뜻을 못 읽은 단어는 뜻 칸이 비어서 나오니 직접 적어주세요.

### GitHub Pages 켜는 법 (처음 한 번)
1. 저장소 Settings → General 맨 아래 Danger Zone → Change visibility → Public
   (Pages는 무료 계정에서 공개 저장소만 가능해요. 앱 코드만 공개되고 단어장 데이터는 공개되지 않아요.)
2. Settings → Pages → Build and deployment → Source: Deploy from a branch, Branch: main / (root) → Save
3. 1~2분 뒤 위 주소로 접속

## 아티팩트 버전

`index.html`에서 `<!--ARTIFACT-START-->`~`<!--ARTIFACT-HEAD-END-->` 부분과
`<body>`~`<!--ARTIFACT-END-->` 부분을 이어 붙이면 claude.ai 아티팩트용 페이지가 돼요.
아티팩트로 열면 계정 저장(기기 간 동기화)과 Claude 사진 읽기를 써요.
